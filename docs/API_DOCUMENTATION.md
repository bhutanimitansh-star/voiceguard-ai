# VoiceGuard AI — API Documentation

Base URL (local dev): `http://localhost:8000/api`

Interactive docs auto-generated by FastAPI are also available at:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

---

## POST /api/predict

Upload an audio file and receive a Human vs AI-generated voice verdict.

**Request**
`Content-Type: multipart/form-data`

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| file  | File | Yes | Audio file (`.wav`, `.mp3`, `.flac`, `.m4a`), max 25MB |

**cURL example**
```bash
curl -X POST "http://localhost:8000/api/predict" \
  -F "file=@sample_clip.wav"
```

**Response `200 OK`**
```json
{
  "prediction": "AI Voice",
  "confidence": 96.4,
  "human_probability": 3.6,
  "ai_probability": 96.4,
  "processing_time": "1.42 s",
  "suspicious_regions": [
    { "start_sec": 1.2, "end_sec": 1.65, "intensity": 0.81 },
    { "start_sec": 3.4, "end_sec": 3.9, "intensity": 0.72 }
  ],
  "waveform_png_base64": "iVBORw0KGgoAAAANSUhEUgAA...",
  "melspectrogram_png_base64": "iVBORw0KGgoAAAANSUhEUgAA...",
  "gradcam_png_base64": "iVBORw0KGgoAAAANSUhEUgAA...",
  "acoustic_features": {
    "mfcc_mean": -12.4,
    "mfcc_std": 18.7,
    "chroma_mean": 0.42,
    "spectral_centroid_mean": 2140.5,
    "spectral_rolloff_mean": 4230.1,
    "zcr_mean": 0.083,
    "pitch_mean_hz": 187.3,
    "pitch_std_hz": 22.1,
    "hnr_db": 6.8
  },
  "duration_sec": 6.24
}
```

**Error responses**
| Status | Reason |
|--------|--------|
| 400 | Unsupported file extension or file exceeds 25MB |
| 500 | Internal inference failure (see `detail` field) |

## GET /api/history

Returns stored prediction history, most recent first.

**Query params**

| Param | Type | Default | Description |
|-------|------|---------|-------------|
| limit | int  | 100     | Max number of records to return |

**Response `200 OK`**
```json
{
  "count": 2,
  "items": [
    {
      "id": 2,
      "filename": "clip_ai.wav",
      "prediction": "AI Voice",
      "confidence": 96.4,
      "human_probability": 3.6,
      "ai_probability": 96.4,
      "processing_time": "1.42 s",

      "created_at": "2026-08-30T10:15:22.123Z"
    },
    {
      "id": 1,

      "prediction": "Human",

      "duration_sec": 5.02,
      "created_at": "2026-08-30T10:12:04.981Z"
    }
  ]
}
```

## DELETE /api/history

Clears all stored prediction history.

**Response `200 OK`**
```json
{
  "deleted_count": 2,
  "message": "History cleared successfully."
}
```

## GET /api/health

Liveness/readiness probe.

**Response `200 OK`**
```json
{
  "status": "ok",
  "model_loaded": true,
  "device": "cpu",
  "version": "1.0.0"
}
```

`model_loaded: false` indicates the server is running with randomly
initialized weights because no trained checkpoint was found at
`backend/models/checkpoints/voiceguard_cnn_bilstm_attn.pt` — run
`training/train.py` to produce one before relying on predictions.
